# AmazingAPP

AmazingAPP is a simple Python project used to demonstrate a clean Git workflow.

## Purpose

This repository is used to practice:

- creating branches
- working with feature branches
- merging branches into `develop`
- handling merge conflicts
- resolving conflicts safely

## Planned Features

AmazingAPP will include a basic calculator with four operations:

- addition
- subtraction
- multiplication
- division

Each operation will be implemented in a separate feature branch.

## Branching Strategy

- `main` starts as an empty stable branch.
- `develop` is created from `main`.
- `docs/readme` adds the initial project documentation.
- Feature branches are created from `develop`.
- Completed work is merged back into `develop`.
